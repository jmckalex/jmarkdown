\section{Code with \mintinline{text}{<b>x</b>} in a heading}

HTML specials in code are shown, never parsed: \mintinline{text}|</>|, \mintinline{text}|<b>x</b>|, \mintinline{text}|a && b|,
\mintinline{text}|x < y|, \mintinline{text}|"quoted"|, and \mintinline{text}|<img src=x onerror=alert(1)>| stays text.

\begin{tabular}{ll}
\toprule
case & code \\
\midrule
tags & \mintinline{text}|<b>x</b>| \\
operators & \mintinline{text}|a && b|, \mintinline{text}|x < y| \\
\bottomrule
\end{tabular}

\begin{minted}{html}
<b>x</b> & "q" < y
\end{minted}

\begin{minted}{text}
<b>x</b> & "q" < y
\end{minted}

\begin{minted}{text}
<b>x</b> & "q" < y
\end{minted}
