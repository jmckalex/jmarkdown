Code that shows \mintinline{text}|\end{minted}| — on a line of its own, indented, or after
other text — printed only up to it in LaTeX, and stopped the build.

\ifcsname jmdmintedlatex\endcsname\else\newminted[jmdmintedlatex]{latex}{}\fi
\begin{jmdmintedlatex}
\begin{minted}{js}
const greet = (name) => `Hello, ${name}!`;
\end{minted}
\end{jmdmintedlatex}

The same language again:

\ifcsname jmdmintedlatex\endcsname\else\newminted[jmdmintedlatex]{latex}{}\fi
\begin{jmdmintedlatex}
\begin{listing}[htbp]
\begin{minted}{python}
print("hello, world")
  \end{minted}
\caption{A hello-world program}
\end{listing}
\end{jmdmintedlatex}

No language, and the end after other text:
