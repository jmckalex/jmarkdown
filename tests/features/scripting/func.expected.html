A function may return markdown, strong and italic, lexed inline.

Trailing prose is not part of it: one (see above), and a brace inside a string does not end it: 1 character.

Prose that merely mentions the func(x) notation stays prose.

A function that throws leaves a named error, [func(…) failed: boom], and the build carries on.
