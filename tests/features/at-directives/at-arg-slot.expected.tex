\section{The argument slot}

A handler that declares \mintinline{text}|arg: true| takes a leading parenthesis:
\includegraphics[width=0.2\linewidth]{figs/a.png} — and the block form puts the
\mintinline{text}|+| on the name, before the argument.

\includegraphics[width=0.3\linewidth]{figs/b.png}

Every other name leaves parentheses to prose. A registered name that did not ask
for an argument keeps its parenthetical — styled(like this one) — and
an unregistered @note(aside) is not a directive at all. An address such as
\href{mailto:me@example.com}{me@example.com} is untouched, as is a bare  with no argument of any kind.

A block form buried mid-sentence —  — is misplaced, and
says so.
