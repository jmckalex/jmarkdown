The argument slot

A handler that declares arg: true takes a leading parenthesis: — and the block form puts the + on the name, before the argument.

Every other name leaves parentheses to prose. A registered name that did not ask for an argument keeps its parenthetical — styled(like this one) — and an unregistered @note(aside) is not a directive at all. An address such as me@example.com is untouched, as is a bare [@image: no source] with no argument of any kind.

A block form buried mid-sentence — [@image+ must start its own line] — is misplaced, and says so.
