At-directive disambiguation

Bare names are directives only when registered: renders an (empty) span, but @unknown stays literal text.

An @ glued to a word is prose, never a directive — user@span — and a real email like me@host.com still autolinks.

A bracket form is a directive anywhere it appears: hi.

A +-block directive is an error if it does not start its own line: a stray [@callout+ must start its own line] mid-paragraph is flagged.
